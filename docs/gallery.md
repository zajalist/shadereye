# Gallery

Rendered outputs from the bundled `examples/` shaders. These assets are
committed under [`media/`](../media) and were generated by rendering the example
shaders through the real `shadereye-render` engine (and, for the WebGL clip, a
real browser WebGL2 / GLSL ES 3.00 pipeline).

## Plasma — native (`wgpu`)

[`media/plasma.gif`](../media/plasma.gif) ·
[`media/plasma.mp4`](../media/plasma.mp4)

`examples/plasma.glsl` — an animated Shadertoy-style plasma using stacked sines
of the UV coordinates modulated by `iTime`, mapped through a cosine palette.
Rendered at 512×288, 90 frames across one full `iTime` period
(`t0=0.0 … t1=6.2832`) so the loop is seamless.

## Plasma — browser (WebGL2 / GLSL ES 3.00)

[`media/webgl_demo.gif`](../media/webgl_demo.gif) ·
[`media/webgl_demo.mp4`](../media/webgl_demo.mp4) ·
[`media/webgl_demo.html`](../media/webgl_demo.html)

The same `plasma.glsl` body ported into a GLSL ES 3.00 fragment shader
(`precision highp float;` + Shadertoy uniforms) and run in a real browser
WebGL2 pipeline — the same runtime class the `run_in_browser` tool drives.

## Raymarch — the compile→see→fix loop

[`media/raymarch-fix.png`](../media/raymarch-fix.png)

`examples/raymarch_broken.glsl` — the intentionally broken raymarcher from the
README transcript (integer-division gotcha), shown before and after the fix.
BEFORE: `float t = 1 / 2;` (integer division → `0`, blue channel dead).
AFTER: `float t = 1.0 / 2.0;` (blue channel restored).

The full animated agent transcript of this loop is
[`media/loop.gif`](../media/loop.gif) (reproducible with
[`media/loop.tape`](../media/loop.tape) via `vhs`).

## Regenerating

The `dump_frames` example renders any shader file to zero-padded PNG frames:

```sh
cargo run --release -p shadereye-render --example dump_frames -- \
  examples/plasma.glsl out/ 512 288 90 0.0 6.2832
```

Then encode with `ffmpeg` (two-pass palette for GIFs). See
[`docs/DEMO.md`](DEMO.md) for the full self-filming kit.
